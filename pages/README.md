# Pages

這個資料夾保存 `index.html` 內各頁面的獨立維護版本。

目前網站仍以 `index.html` 作為正式入口，並保留原本的 SEO、JSON-LD、canonical 與頁面內容。這裡的檔案用途是讓各頁內容更容易閱讀、比較與後續整理。

對應關係：

- `home.html`：首頁
- `leak-repair.html`：冷熱水管免打牆止漏
- `waterjet.html`：水刀疏通通管
- `high-pressure.html`：高壓清洗服務總覽
- `large-vehicle-cleaning.html`：大型車輛清洗
- `construction-vehicle-cleaning.html`：工程車清洗
- `oil-cleaning.html`：地面油污清洗
- `water-tank-cleaning.html`：水塔清洗
- `fish-pond-cleaning.html`：魚池清洗
- `enterprise-food.html`：企業餐飲排水維護方案
- `process.html`：施工流程
- `area.html`：服務範圍
- `faq.html`：常見問題
- `contact.html`：聯絡我們

若未來要改成真正多頁網站，建議再同步規劃每頁的 `title`、`description`、canonical、Open Graph 與 `sitemap.xml`，避免 SEO 訊號混亂。
